# Family Schedule Prototype

Open `index.html` in a browser to try the prototype.

The prototype stores data in browser localStorage. It does not use login, invite links, Supabase, or a backend yet.

## What It Demonstrates

- Add, edit, and delete family events.
- Mark each family member as available, unavailable, or unsure.
- See response counts per event.
- Use a mobile-first layout.

## Production Next Step

Move the same concepts into a Next.js app and replace localStorage with Supabase tables:

- `members`
- `events`
- `responses`
